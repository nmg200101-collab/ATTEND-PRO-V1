# ATTEND-PRO V158 — Release Notes

V158 reorganizes the Store Management screen for faster, clearer daily use without changing the underlying functions.

### Changed
- Store Management now opens with six clear task-based sections.
- Existing options are grouped into organized submenus with a concise description.
- Store information, GPS, locks, appearance, language, guide and privacy are grouped under Store Settings.
- Employee management, attendance methods, shift/grace settings and external fingerprint are grouped under Employees and Shifts.
- Connectivity and Devices provides a readiness/status entry only; locked transport logic is not modified.
- Reports and receiver access remain routed through the existing Reports center.
- Messages and voice controls are grouped together.
- Backup/restore and higher system administration are grouped separately.
- Legacy Advanced Settings remains available as a fallback so no previous option is lost.

### Not changed
Bluetooth/BLE, Wi-Fi/Hotspot/LAN, Receiver V149, RC29 pairing/GATT protocol, GPS engine, attendance engine, message transport, proof delivery, backup engine and server behavior.
