# V169 Face Security Audit

## Baseline
- Parent field baseline: V168 Noise Robust Voice.
- V168 voice is treated as locked in this release.

## Changed runtime files
- `buildsrc/store-app/src/main/java/com/attendpro/store/FaceSignatureEngine.kt`
- `buildsrc/store-app/src/main/java/com/attendpro/store/FaceTemplateProtectorV169.kt`
- `buildsrc/store-app/src/main/java/com/attendpro/store/MainActivity.kt`
- Store/Employee Gradle version metadata.

## Security controls
- AES/GCM/NoPadding using Android Keystore alias `attend_pro_face_v169`.
- Random IV generated by Android cryptographic provider for every seal operation.
- Employee ID used as AES-GCM AAD for face templates; reference files use `ref:<employeeId>`.
- Encrypted template prefix: `fenc1:`.
- New local face signature format: `fh2:` and multi-template `fm2:`.
- Identity threshold is never reduced because of weak image quality.
- Interactive liveness requires both identity continuity and measured Euler-angle movement.
- Face test mode remains non-attendance.
- Existing authentication failure/rate limiting remains active.

## Limitations stated explicitly
V169 is an offline local face-verification hardening layer. It is not claimed to be a certified commercial anti-spoofing system or a neural face-recognition model. The liveness challenge materially improves resistance to a single static image but cannot guarantee resistance against every advanced presentation attack.
