ATTEND-PRO 1.9.82 Anti-Tamper & IP Hardening
- Runtime official signing-certificate enforcement for release builds.
- R8 minification/obfuscation + resource shrinking for Store and Employee release APKs.
- HTTPS-only Android network security configuration.
- FLAG_SECURE on Store/System administrative screens.
- Active debugger/tracer/instrumentation detection on privileged System Management screens.
- Pairing/BLE/QR/GATT/Heartbeat/Local-message protocol must remain unchanged by CI guard.
- This is defense-in-depth; no mobile APK can be made impossible to reverse engineer.
